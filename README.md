# 🎮 Tic Tac Toe Game

A simple and interactive Tic Tac Toe game built using **HTML, CSS, and JavaScript**.

## 🌐 Live Demo

🔗 https://tic-tac-toe-priyansh.netlify.app/

## 🚀 Features

- Two-player gameplay (X and O)
- Winner detection
- Draw detection
- Reset game functionality
- New Game button
- Responsive UI
- Clean and beginner-friendly code

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
